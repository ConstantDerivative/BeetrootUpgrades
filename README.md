# BeetrootUpgrades
A datapack & resource pack for upgrading your beetroot so you can farm as much as you want without filling up your inventory.
This was made for the **MODSMP (Math Olympiad Discord SMP)**, a server that uses beetroot as its main form of currency.
## Features
* Craft 9 regular beetroot into 1 **level 1 beetroot!**
* Go up to **level 8 beetroot** (9^8 beetroot = 43,046,721)
* Decreases rate of seeds harvested per beetroot.
